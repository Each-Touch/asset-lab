1. **Git 公网仓库绝不泄露付费全量包**：必须在 `.gitignore` 中写死忽略 `releases/*/*-full-*` 与 `releases/*/paid_*`，每次 `git add` 前核查 `git status`，确保 GitHub 只托管公开试听展示页与免费 Demo。

4. **纯 DSP/代码零 AI 标签红利**：全程不用生成式 AI，诚实选 `Generative AI: No`，在 itch.io Game Assets 市场对反感 AI 版权隐患的独立游戏团队极具吸引力。
