# 干中学｜游戏素材包付费转化与避坑库

1. **Git 公网仓库绝不泄露付费全量包**：必须在 `.gitignore` 中写死忽略 `releases/*/*-full-*` 与 `releases/*/paid_*`，每次 `git add` 前核查 `git status`，确保 GitHub 只托管公开试听展示页与免费 Demo。
2. **「Paid + Free Demo」双文件漏斗**：itch.io 上仅给试听/试用包勾选 `This file is a demo and can be downloaded for free`，主包保留在付费墙后，让犹豫的玩家免费测试音质/兼容度后再一键买单全量包。
3. **网页端真试听提高购买率**：GitHub Pages 展示页放 10 类真实 OGG 试听条 + 波形预览图 + 完整 `TRACKLIST` 列表，先建立专业度再跳转 itch.io 买单。
4. **纯 DSP/代码零 AI 标签红利**：全程不用生成式 AI，诚实选 `Generative AI: No`，在 itch.io Game Assets 市场对反感 AI 版权隐患的独立游戏团队极具吸引力。
5. **2026-11-22 首包实战固化**：
   - 本机 `ffmpeg` 未编入 `libvorbis` 时，`.ogg` 走 `-c:a libopus -b:a 128k`，网页 `<audio>` 试听样本单独用 `libmp3lame -q:a 2`（全端 Safari/Chrome 通吃，零播放失败）；
   - PIL 预览图左边栏分类名与文件名分 3 行竖排并用 `draw.text` `anchor="mm"` 居中顶部角标，避免长文件名压进右侧波形框；
   - itch.io `Paid ($2.99)` + `upload[...][demo]` 勾选在 `Collected by itch.io, paid later` 模式下直接线上生效，主包传完再传 Demo 包并只给 Demo 包打勾最稳。
